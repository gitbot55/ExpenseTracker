# 💰 Full-Stack Expense Tracker Web Application

A full-stack Expense Tracker web application built using Python and Flask that allows users to manage personal expenses, organise transactions into categories, and monitor spending through interactive visualisations.

## ✨ Features

- **User Authentication:** User registration, login, and secure session management.
- **Expense Management:** Add and manage personal expense records.
- **Category Management:** Organise expenses into different categories.
- **Transaction History:** View and track recorded financial transactions.
- **Interactive Dashboard:** Visualise spending patterns through charts and summaries.
- **Data Visualisation:** Integrated Chart.js for interactive financial charts.
- **Database Integration:** SQLite database for storing user accounts and transaction records.
- **Security:** CSRF protection for improved application security.

## 🛠️ Technologies Used

**Backend:**
- Python
- Flask
- SQLite

**Frontend:**
- HTML
- CSS
- JavaScript
- Chart.js
